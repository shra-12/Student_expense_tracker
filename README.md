Student Expense Tracker 

My first Python project — a beginner-friendly expense tracker built using Python.

📌 About the Project

The Student Expense Tracker is a simple command-line program that helps students record their expenses and calculate their total spending.

The user enters the expense name, category, and amount. After entering all expenses, the program displays the details of each entry and the total expense.

✨ Features

- Enter multiple expense records.
- Add an expense name and category.
- Enter the amount spent in rupees.
- Display each expense with its details.
- Calculate the total expenditure.
- Choose the number of expense entries.

🛠️ Technologies Used

- Language: Python
- Concepts: Functions, loops, user input, type conversion, return statements, and arithmetic operations.

▶️ How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open "main.py" in a Python editor.
4. Run the program.
5. Enter the number of expenses, then provide the name, category, and amount for each expense.
